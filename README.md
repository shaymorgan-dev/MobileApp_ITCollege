## 📖 О проекте

Этот проект — моя индивидуальная работа по дисциплине **«Введение в специальность. Программирование»** на 1-м курсе в IT-колледже. 

**Expenses App** — это кроссплатформенное мобильное приложение для удобного и быстрого контроля личных финансов. Оно позволяет пользователю записывать ежедневные траты, распределять их по категориям и наглядно видеть статистику своих расходов.

Приложение разработано с использованием фреймворка **Flutter**, что позволяет запускать его не только на Android и iOS, но и на Web, Windows и macOS.

## ✨ Основные возможности (Features)

*   **Добавление транзакций** — быстрое внесение доходов и расходов.
*   **Категории** — удобная сортировка трат по категориям (Еда, Транспорт, Развлечения, Учеба и т.д.).
*   **Статистика** — наглядное отображение расходов (графики и суммы).
*   **Локальное сохранение данных** — ваши записи не теряются при перезапуске приложения (используется локальная база данных/хранилище).
*   **Адаптивный интерфейс** — приложение отлично выглядит на смартфонах и планшетах.
*   **Material Design** — современный и понятный пользовательский интерфейс.
